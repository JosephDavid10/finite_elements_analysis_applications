# finite_elements_analysis_applications
Exploration of FEA techniques on structural engineering problems

## frame_example1
file: [frame_example1.py](./frame_example1.py)

Application of the class Frame2d in [fea_models.py](./fea_models.py) to solve a little bit more complicated frame structure with hinges and different kinds of loads. The solver aims to obtain the total displacements and reactions on each node.
